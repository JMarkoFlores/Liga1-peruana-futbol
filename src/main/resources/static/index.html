Plataforma profesional para la administración de encuentros, cálculo dinámico de estadísticas y tabla de posiciones oficial, impulsada por arquitectura REST con Spring Boot, JPA y persistencia en MySQL.

CRUD de Partidos

Crea, actualiza y elimina partidos con validaciones de marcador, fecha y jornada deportiva directamente en MySQL.

Cálculo Automático

Algoritmo de clasificación profesional: 3 pts por victoria, 1 pt por empate y desempate por DG y GF.

API REST Rápida

Servicios JSON desacoplados bajo la ruta /api/partidos y /api/tabla-posiciones con soporte CORS.

Modo Oscuro & Móvil

Interfaz moderna basada en Tailwind CSS con alternador de tema persistente y menú responsivo para teléfonos y tablets.
