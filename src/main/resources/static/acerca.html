FútbolStats: Sistema de Registro y Tabla de Posiciones

Este proyecto reorienta una práctica inicial de CRUD hacia un sistema completo de gestión de encuentros de fútbol y generación dinámica de tablas de clasificación oficial. Cuenta con persistencia relacional en MySQL, cálculo inteligente en la capa de negocio y un frontend desacoplado servido estáticamente.

🛠️ Stack Tecnológico

☕

Backend (Java & Spring)

  • • Java 21 LTS (JDK moderno)
  • • Spring Boot 4.x (Spring Web MVC)
  • • Spring Data JPA con Hibernate
  • • Lombok para código limpio
  • • CORS habilitado para clientes externos
🐬

Persistencia Relacional

  • • MySQL Server en localhost:3306
  • • Base de datos: sistema
  • • Tabla: partidos con AUTO_INCREMENT
  • • Estrategia DDL: update automático
🎨

Frontend & UI

  • • Tailwind CSS vía CDN con Dark Mode por clase
  • • JavaScript Vanilla (ES6+) nativo con Fetch API
  • • Notificaciones Toasts interactivas
  • • Drawer responsive para dispositivos móviles
  • • Servido como recursos estáticos desde Spring Boot

🏛️ Arquitectura en Capas

El proyecto sigue estrictamente el principio de responsabilidad única dividiendo el flujo en 4 capas dentro del paquete com.sistemas.ejemplo:

1. Entidad JPA
Partido.java

Mapea la tabla con campos de equipos, goles, jornada y fecha.

2. Repositorio
PartidoRepositorio.java

Hereda JpaRepository y añade ordenamiento por jornada y fecha.

3. Servicio
PartidoServicio.java

Lógica CRUD y algoritmo de cálculo de estadísticas (EquipoStats).

4. Controlador REST
PartidoControlador.java

Expone endpoints JSON con respuestas HTTP y CORS abierto.

📡 Catálogo de Endpoints REST

Rutas disponibles en la API para consumo de clientes

POST /api/partidos
Registra un nuevo partido en la base de datos
GET /api/partidos
Lista todos los partidos ordenados por jornada y fecha
GET /api/partidos/{id}
Obtiene los detalles de un encuentro específico
PUT /api/partidos/{id}
Actualiza los datos o marcador de un partido existente
DELETE /api/partidos/{id}
Elimina un partido por su ID
GET /api/tabla-posiciones
Calcula y devuelve la clasificación general en tiempo real
